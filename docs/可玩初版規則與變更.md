# 公路求生可玩初版規則與變更

此版依最新指示取代早期文件中衝突的時間、21 天目標與開局保障設定。可玩專案為 `road-game`，完整操作與實作範圍見 [README](../README.md)。

| 項目 | 最新規則 |
| --- | --- |
| 時間 | 實際運行 60 秒為一天，事件決策、暫停與管理介面停止流逝 |
| 勝利 | 存活且通過第 30 天 06:00 的當日里程結算 |
| 失敗 | 健康歸零、截止未達里程、確認逆行 |
| 生存方式 | 可探索、交易、援助、求援、掠奪、製作；不要求道德路線或共同任務通關 |
| 差開局 | 允許難解甚至無解；弱勢車系資源點更密，不保證核心物資與通關 |
| 綁定 | 玩家與 NPC 抽到後只能原系晉階，不能換車 |
| 物品空間 | 普通物品佔格，背包與車內共用格數計算；不能無限存放 |
| 工程材料 | 18 種材料使用獨立數值帳本，不佔背包 |
| NPC 社會 | 五個社群與人際關係網、真實物資互助、公開與私人交易、恩怨與死亡 |
| 特殊系統 | 玩家 1% 開局覺醒，18 種原型，未抽中也有正常玩法 |

初版提供道路行駛、建築外觀與文字互動；不同載具類別有對應視覺，尚非 260 套完整美術。現有內容為 106 種物品資料、24 配方、18 建築、12 類路上事件及 99 名持續模擬 NPC，後續應擴充地點專屬分支、車系設備及三十天內容密度。

舊規格所述的完整 18 系統細節、精密 NPC 排程與各車系專精任務仍是後續目標；可玩版具體差異列在專案 README，不以資料表筆數當成所有功能已完成。
